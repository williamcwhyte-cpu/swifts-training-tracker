# Swifts Training Tracker

Phone-friendly training tracker for Carnmoney Colts Swifts 2016s.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `swifts-training-tracker`.
2. Upload `index.html`, `app.jsx`, `manifest.webmanifest`, and `sw.js` to the repository root.
3. In GitHub go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. GitHub will display the live site address when publishing completes.
7. Open that address on the personal phone and use **Add to Home Screen** / **Install app**.
8. Use the app's **Share app link** button to send the same site to Mo and Davy.

Records are stored locally in each browser. Use Export/Import to move training records between phones.
